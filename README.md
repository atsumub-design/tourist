## Project Description

The Pangasinan Heritage Digital Showcase is a responsive and
mobile-first web application developed to promote the cultural
heritage, tourism destinations, traditions, food, festivals, and
local identity of Pangasinan.

The website was developed using Next.js and Static Site Generation
(SSG) and deployed as a static website through GitHub Pages.

## Main Features

- Heritage information
- Tourism destinations
- Local culture and traditions
- Local food
- Festivals and celebrations
- Local artists and artisans
- Community features
- Responsive mobile-first design
- Accessible navigation
